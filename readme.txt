Logs 404 errors, suggests the closest matching page and creates 301 redirects in one click.

== Description ==
* Logs 404 paths with hit counts (no IPs, no user agents)
* Suggests the closest existing page by slug similarity
* One-click 301 redirects, with redirect-loop detection
* CSV import and export
* WP-CLI: `wp sentinel list`, `wp sentinel redirect`, `wp sentinel prune`
* No external services, no tracking

== Installation ==
Upload the plugin, activate it, then open Tools > 404 Sentinel.
